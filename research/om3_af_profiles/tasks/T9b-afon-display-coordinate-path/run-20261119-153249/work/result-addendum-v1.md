4. **Findings.**

   1. OBSERVED-EMU. During the idle, thunk `0x6041a1f9` with `d0 = 0x88b2` and `d1 = 0` returns to `0x60419360`. The call site is `0x6041935b` (`call 0x6041a1f9,[],0x4`). It runs twice in the pre-setter idle and twice in the post-setter idle. The returned `d0` is 526, then 412. At the return, `a0 = 0x629526c0`. The caller of that wrapper is `0x603f15d8` in function `0x603f15b1`, observed return `0x603f15df`, returned value 526 then 412. That function then calls `0x604050be` and returns. It returns the cell index. It does not store 356 or 198.
   2. OBSERVED-EMU. The first stores of the exact values 356 and 198, after the setter writes 412, are `movhu D1,(0xec,sp)` at `0x611852e9` and `movhu D1,(0xee,sp)` at `0x61185307`, both in routine `0x61184e51`. At that store the stack inputs were point (16, 10), size constants (3, 3), object `0x62c54158`, and the word at object+`0x364` equal to 406. The routine was entered once in that 500 ms idle. The frame union became (356, 198) 65×71. Subject 0. Cell 412.
   3. OBSERVED-EMU. The same values are then copied. `0x610c8c62` writes 356 to `0x62c546c0` and `0x610c8c70` writes 198 to `0x62c546c2`. Those instructions are in `0x610c8c2e` and store to object+8 and object+`0xa`, so the object base is `0x62c546b8` and the fields are the halfwords at +8 and +`0xa`. Later, the copy loop at `0x610deb9d` writes 356 to `0x62bd71ec` and 198 to `0x62bd71ee`. Earlier in the same idle that loop wrote 417 and 265 to those two addresses, then 436 and 286. The loop copies four halfwords. The moved-frame capture includes the first two.
   4. OBSERVED-EMU. The caller of `0x61184e51` on that idle is the call at `0x61184e30` in function `0x61184dd6`. `mdr` and the word at SP+`0x10` were both `0x61184e35`, the return of that call. The function calls the origin routine only after two checks through `0x610cd5ac` return nonzero. `0x61184dd6` has no `cd` or `dd` caller in the image. Dirty byte `0xa32bfb32` was already 1 before this setter call, still 1 after it, and 1 at the origin entry. This run does not show the setter raising that byte, and it does not show the byte being read on the way in. The flag writer `0x610f7172` ran 4 times in the same idle. The dirty store at `0x6006355e` ran 0 times in experiment 3’s idle.
   5. OBSERVED-EMU. Seeded T6 AF-ON down: owner 2, target `11 02 03 00 01 00 01 00 00 00` (first halfword 529), cell 526, union still (417, 265) 66×70, subject 0. The origin routine’s entry count during the press and the following 400 ms was 0. The flag writer ran 3 times.
